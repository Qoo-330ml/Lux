# Web editorial fonts

- `libre-bodoni/` contains Libre Bodoni variable WOFF2 subsets from Google Fonts (v9).
- Both families are distributed under SIL Open Font License 1.1; retain each directory's `OFL.txt` with the font files.
- The locally bundled faces are used for selected home and media-detail titles so desktop and mobile do not depend on installed system fonts.

Sources:

- https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@400..700&display=swap
- https://fonts.googleapis.com/css2?family=Libre+Bodoni:wght@400..700&display=swap
- https://github.com/google/fonts/tree/main/ofl/notoserifsc
- https://github.com/google/fonts/tree/main/ofl/librebodoni

Chinese editorial headings use the operating system serif stack; no Noto Serif SC subset is bundled.
