# LUX-074 继续观看和已看阈值

## 范围

根据用户独立的播放状态生成 Resume 列表：默认播放到 95% 视为已看，且位置至少达到 2 分钟才进入继续观看。用户可单独调整自动已看百分比，管理员可调整全局最小继续观看位置。

## 实现

- [x] `GET /Users/{userId}/Items/Resume` 按用户状态、媒体时长和阈值过滤并分页。
- [x] 默认自动已看阈值为 95%，最小继续观看位置为 1,200,000,000 ticks（2 分钟）。
- [x] 新增用户设置 GET/PATCH，可调整个人 `playedPercent`；管理员设置继续保留 `resumeMinTicks`。
- [x] 过滤已看、无时长和已超过已看百分比的条目，按最后播放时间稳定排序。
- [x] 播放进度达到用户 `playedPercent` 或停止事件达到阈值时，自动标记电影/单集；默认阈值为 95%。
- [x] 季度和剧集按未删除且有可用播放源的单集聚合已看状态，空容器不自动标记。

## 验证

- 测试覆盖默认 95% 边界、管理员调整继续观看最短进度、自动已看、季度/剧集聚合、取消单集已看、用户状态和 Resume 返回。

## 兼容说明

- LUX-075 的显式已看 API 仍保留，用于客户端手动标记和取消。
- 自动已看只针对有可用播放源的电影/单集；季度和剧集状态由其可播放单集状态聚合。
