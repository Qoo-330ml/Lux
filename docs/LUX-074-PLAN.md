# LUX-074 继续观看和已看阈值

## 范围

根据用户独立的播放状态生成 Resume 列表：默认播放到 90% 视为已看，且位置至少达到 2 分钟才进入继续观看。管理员可调整百分比和最小位置。

## 实现

- [x] `GET /Users/{userId}/Items/Resume` 按用户状态、媒体时长和阈值过滤并分页。
- [x] 默认阈值为 90% 与 1,200,000,000 ticks（2 分钟）。
- [x] 新增管理员设置 GET/PATCH，可调整 `resumePlayedPercent` 和 `resumeMinTicks`。
- [x] 过滤已看、无时长和已超过已看百分比的条目，按最后播放时间稳定排序。

## 验证

- 测试覆盖默认 90% 边界、管理员放宽阈值、用户状态和 Resume 返回。

## 明确不做

- 本阶段不自动按阈值将状态写成已看；显式已看操作属于 LUX-075。
