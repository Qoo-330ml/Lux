# Lux 更新日志

Lux 的版本变更记录，从 `0.1.0` 开始按版本倒序排列。

> 格式：本日志按 git-cz（Conventional Commits）的类型分组，每个条目就是一行 `type(scope): 摘要`；
> 类型包括 `feat`（新功能）、`fix`（修复）、`perf`（性能）、`refactor`（重构）、`docs`（文档）、`build`（构建）、`test`（测试）、`chore`（杂项），`💥 BREAKING CHANGES` 表示破坏性变更。
> 版本开头用一句话说明这个版本的主线，细节留在提交和对应文档里。日志根据源码版本、Git 提交和已记录的验证结果整理；日期是对应提交日期，不等同于已发布到各渠道的正式发布日期。每个版本只记录主要的用户可见变化，不逐条复制 Git 提交。
>
> 发版时两处都要改：本文档，以及应用内「设置 → 更新日志」页面使用的内置列表：新版本条目追加到 `web/src/features/admin/changelog/releases/` 下对应大版本的文件（如 `v0-7.ts`）；新大版本需新增文件，并在 `releases/index.ts` 中按倒序插入（该页面不读取本文件）。
