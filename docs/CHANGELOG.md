# Lux 更新日志

Lux 的版本变更记录，从 `0.1.0` 开始按版本倒序排列。

> 说明：仓库当前没有 Git tag。本日志根据源码版本 bump 提交和仓库初始提交整理；日期是对应提交日期，不等同于已发布到各渠道的正式发布日期。每个版本只记录主要的用户可见变化，不逐条复制 Git 提交。

## [0.3.5] - 2026-08-31

### Fixed

- 修复隐私浏览模式拒绝 Cookie 或 Web Storage 时，登录后的当前页面无法继续执行收藏、已看、播放和退出等写请求的问题；客户端现在以内存保留登录响应中的 CSRF nonce，并在退出时清理。
- 修复下载的 Bilibili 弹幕 XML 包含标准 XML 声明时无法解析的问题；现在支持受限的版本、编码和 standalone 声明，同时继续执行 XML 安全与大小校验。
- 修复较大的 Bilibili 弹幕 XML 解析结果为空的问题；弹幕条目上限从 5,000 提高到 50,000，同时保留 4 MiB 文件、单条文本长度和总时长限制。

### Changed

- 增加弹幕匹配并发数和覆盖已有弹幕文件的配置；并发数支持由 0 表示不设插件级限制（仍受宿主资源上限约束），并可选择覆盖同名 XML。
- 增加 Docker 扫库并发环境变量 `LUX_SCAN_CONCURRENCY`；支持 `1-1024`，设置为 `1024` 可增加扫库线程，未设置时默认 32 路并会根据资源压力自动降级。

## [0.3.4] - 2026-08-31

### Fixed

- 修复 Lux Web 远程 HTTP(S) `.strm` 播放可能进入需要 CORS `fetch` 的客户端 HEVC/MKV fallback 的问题；该类来源保持 Lux 受保护入口后的原生直放和 307 重定向，媒体字节仍由浏览器直连最终地址。
- 修复本地 NFO 中的评分未写入媒体目录索引的问题；该评分现在会用于推荐排序并标记其 NFO 来源。
- 修复剧集重新匹配元数据时写入简化 NFO 或保留错误根标签的问题；现在会以 `tvshow.nfo` 写入完整剧集元数据，并保留演员、制作信息及最后播出日期。
- 修复拥有多个媒体源或音轨的条目可能占满推荐查询分页、导致首页推荐数量不足的问题；分页现在在逻辑媒体条目层完成。
- 修复 NextEmby 请求管理员 Emby 用户列表时缺少 `/Users` 兼容端点的问题；该端点同时支持根路径与 `/emby` 前缀，并仅允许具备服务器管理权限的用户访问。
- 修复 Emby 会话响应缺少当前播放条目和时长、导致部分客户端无法识别播放状态的问题；当会话未上报时长时，会安全回退到目录中的媒体时长。
- 修复未知 Lux API、Emby API 或顶层 Emby 兼容路径可能回退为 Web HTML 的问题；这些请求现在统一返回 JSON 格式的 404。
- 修复部分反向代理在登录时丢弃 `Set-Cookie` 后，Lux Web 无法恢复 CSRF 令牌并继续进行写操作的问题；客户端现在会从受保护的登录响应中恢复同源 CSRF Cookie，并在登出成功后清除它。
- 修复反向代理丢失可读 CSRF Cookie 时，Web（包括旧版静态入口）的写请求无法通过校验的问题；客户端现在持久化登录响应中的 CSRF nonce，并在登出时清理。
- 兼容隐私模式拒绝 Cookie 或 Web Storage 的情况：登录后的当前页面以内存保留 CSRF nonce，收藏、已看、播放和退出仍可完成校验。

### Changed

- 调整播放器章节标记，将其叠加到共享播放时间轴，避免显示重复的进度轨道。
- 调整媒体详情页“已看”操作为紧凑的图标入口，同时保留可访问性标签。

- 优化 Emby 目录列表：批量预读取本地 NFO 和人物附加数据，并保持原有响应顺序，降低多条目列表的重复 I/O。
- 优化待确认元数据与合集刷新：待确认列表批量读取当前条目元数据，合集按 provider ID 索引批量匹配并写入成员，减少数据库往返。
- 优化人物演员视图：按页去重并以有界并发预读取人物关系和头像文件，降低演员列表加载的重复文件访问。
- 调整首页推荐：按 UTC 每日 02:00 生成最多 7 条的稳定批次，结合评分、180 天播放活跃度与收藏评分；聚合统计在批次刷新时物化，减少首页读取负担。
- 首页轮播扩展至最多 7 张卡片，媒体库入口改用更紧凑的自适应网格。

## [0.3.3] - 2026-08-30

### Added

- 优化移动端媒体详情页：增加返回、Lux 首页和操作菜单顶部栏，采用全宽沉浸式海报，并改善标题、操作和详情区域的布局。
- 剧集详情在移动端增加可用的竖版海报展示，同时保留桌面端横向剧照布局。

### Fixed

- 修复媒体详情缺少徽标或竖版海报时的回退逻辑，避免标题被错误隐藏或移动端误切换到空的竖版展示。
- 修复移动端详情页身份信息可能被海报渐变遮挡的问题，并恢复顶部返回栏在安全区域内的阴影和淡入层次。
- 修复自动元数据匹配在最高分达到高置信度但候选并列或分差较小时过度进入待确认的问题；现在按搜索结果顺序稳定选择最高分候选，低于阈值或信息不足时仍会保留待确认状态。
- 修复 Emby 迁移遇到重复目标记录时的写入与恢复边界，并确保意外终止的迁移任务会标记为失败，便于管理员诊断和重试。
- 修复实时增量扫描并发创建同类型活动任务时将预期冲突记录为错误的问题，并为活动任务类型增加数据库级约束。
- 修复播放器时间显示与时间轴布局未对齐的问题，改善窄屏下时间控件的可用空间和响应式排列。
- 修复移动端媒体详情操作区和剧集详情层级间距错位的问题，让收藏、已看和更多操作在同一行显示，并恢复层级、演职员和 NFO 区域的紧凑衔接。
- 修复远程 `.strm` 通过 Lux 重定向播放时设置匿名 CORS 模式可能导致上游源失败的问题；播放器不额外设置 CORS 模式，媒体字节仍由浏览器直连最终地址。
- 修复 `ffprobe` 返回 `matroska,webm` 等容器别名时未识别为客户端 MKV 回退候选的问题。
- 修复 Lux Web 对远程 HTTP(S) `.strm` 直接访问上游 URL 的问题；播放器恢复使用短期签名的 Lux 播放入口，由服务端携带播放器 User-Agent 解析有限重定向并返回 307，媒体字节仍由浏览器直连最终地址。
- 修复 Docker 应用镜像可能随可变 runtime 标签发生依赖漂移的问题；发布构建现在复用按架构、版本化的 runtime 镜像，并在应用构建时锁定其 manifest digest。

### Changed

- 调整移动端详情内容顺序为剧集层级、演职员和媒体信息，并收紧收藏、已看等操作控件在窄屏下的显示方式。
- 调整移动端详情页海报高度和渐变过渡范围，让海报以更紧凑的沉浸式比例自然衔接到详情内容。

## [0.3.2] - 2026-08-30

### Added

- 增加可持久化的 Emby 迁移范围配置，支持按用户资料、媒体库权限、媒体状态、人物收藏和目标 Lux 媒体库选择迁移内容，并可进一步选择媒体状态字段。
- 增加 Emby 迁移的来源用户分页/搜索、按页候选匹配和可恢复的已处理条目记录，管理员可以更精确地控制迁移范围并追踪跳过原因。
- 增加管理台活动中的客户端 IP 显示；启用 IP 归属地插件且已有缓存结果时，同时显示归属地和运营商信息。
- 增加首页“我的媒体库”和“继续观看”模块的独立可见性设置，并将退出登录入口调整到账户侧栏。
- 增加可选的单媒体字幕读取实验：仅在媒体满足 CORS、Range、Matroska 和有界读取条件时按需解析，远程 `.strm` 仍保持直连且不由 Lux 拉取媒体。
- 将 Emby 迁移配置整理为连接、用户范围和确认执行三步向导，管理员可以在开始迁移前明确检查来源和目标账号。
- 增加窄屏播放顶部栏的 AirPlay 和画中画快捷入口，并将播放版本选择整合到播放器设置面板，减少移动端底部控制栏拥挤。
- 增加本地媒体内嵌 SRT/ASS/SSA 字幕的 source-scoped 按需抽取与浏览器原生 in-band 字幕轨道识别；字幕选择复用当前媒体源，不改变 Direct/HLS/fallback 播放会话，远程 `.strm` 继续不由 Lux 拉取或代理字幕。
- 增加 Emby 迁移源用户分页列表与选定用户迁移能力，管理员可以只迁移指定账号，并在管理台查看对应的迁移报告和匹配结果。
- 增加对 `.strm` 媒体源的弹幕匹配支持，匹配时优先使用已索引的季/集编号，避免仅依赖文件名解析。
- 增加扫描后处理阶段的进度、当前条目和吞吐统计，并在管理台活动浮层和任务列表中展示更准确的扫描状态。

### Fixed

- 修复实时增量扫描在全量调和期间排队过久的问题；全量扫描会在当前批次提交后让出扫描锁，优先处理实时任务，并为受影响的剧集补齐层级元数据任务。
- 修复 Emby 迁移在来源目录映射不完整、多个状态筛选或剧集标题回退时可能丢失可迁移条目的问题；现在保留安全的回退候选和可诊断的跳过报告。
- 修复来源服务限流时读前置继续叠加请求的问题，并将限流重试和坏页恢复限制在有界预算内，避免异常来源造成无界请求。
- 修复首页刷新时辅助数据请求阻塞主要内容，以及管理台页面在加载辅助数据期间无法及时显示主体内容的问题。
- 修复 Emby 迁移向导在窄屏布局中步骤内容和操作控件可读性不足的问题。
- 修复上映日期排序在缺少完整日期时忽略已有年份的问题，并避免元数据补全在空演职员结果下重复重写关系。
- 修复移动端播放器控制布局过于拥挤、弹幕按钮与右侧操作排列不一致，以及音量滑块可用范围和滑块圆点不可见的问题；现在会显示完整音量范围、当前填充进度和可操作圆点。
- 修复视频截图未声明跨域资源模式导致部分播放源无法截图的问题。
- 修复本地 NFO 中已有 Provider ID 未正确回填到媒体条目，以及不完整的 Emby 迁移用户选择仍可能启动任务的问题。
- 修复扫描后处理失败、服务重启和并发领取任务时的 checkpoint 恢复问题，并在文件系统阶段完成后释放扫描锁，避免后处理阻塞其他媒体库开始扫描。
- 修复管理台媒体库卡片未应用当前用户已保存排序的问题。

### Changed

- 优化 Emby 迁移读写链路：按需投影来源字段和媒体状态、复用来源库映射、批量写入用户绑定/匹配/状态、缓存跨用户候选，并最多预读一页来源数据；合成基准与 ARM64 不外推限制记录在 `docs/EMBY-MIGRATION-PERFORMANCE.md`。
- 为 Emby 迁移增加 `media_item_provider_ids` 和标题回退索引及对应数据库迁移，Provider 命中优先于标题查询，标题匹配使用有界的精确/模糊回退。
- 简化媒体库根路径操作和 Emby 迁移向导布局，保留旧插件兼容路径，并在窄屏界面中收紧操作控件。
- 优化管理台导航：在悬停、聚焦或按下导航项时预加载页面模块和主要查询数据，降低页面切换等待时间。
- 优化电影与剧集扫描及元数据重识别任务的批处理路径，减少重复查询、事务提交和数据库关系写入，并补充大媒体库性能记录。
- 调整播放页移动端控制层和中心播放提示的尺寸与响应式行为，保留桌面端完整操作并提升窄屏可用性。
- 移除播放器设置面板中的快捷键提示，简化设置内容并减少移动端占用空间。
- 优化 Emby 迁移流程，减少数据库往返并收紧用户选择、状态合并和任务恢复边界；数据库 schema 更新至 103。
- 优化大媒体库扫描：分批写入剧集和混合库层级、并行处理指纹与变更文件、流式发现目录，并缓存混合库分类探针，降低扫描期间的数据库往返和内存压力。

## [0.3.1] - 2026-08-28

### Added

- 增加 LuxPlayer 控制器、播放引擎与运行时边界，在保留既有原生、HLS 与客户端回退链路的前提下统一播放器状态和会话控制。
- 增加播放器指针手势与平台适配：单击播放/暂停、双击全屏、拖动进度和音量，并适配桌面、触控及窄屏布局。
- 增加播放器诊断、设置面板、顶部栏和模块化控制组件，便于后续独立演进而不改变播放协议。
- 增加当前媒体源的字幕选择、原生 WebVTT 与 Lux 文本字幕叠层，并支持安全的字幕偏移控制。
- 增加受限的 Lux 弹幕读取、调度和显示开关，以及循环播放、画面比例、镜像、AirPlay、隐藏进度条和章节时间轴控制。
- 增加剧集级媒体删除能力：删除剧集时可递归清理其季度、分集下的本地/STRM 媒体源及同名旁车文件，并保留单个媒体源删除语义。
- 增加管理员健康接口的数据库连接池诊断，并支持按 SQLite/PostgreSQL 后端使用默认连接数或通过 `LUX_DB_MAX_CONNECTIONS` 覆盖；Docker Compose 会传递该配置。

### Fixed

- 修复播放会话切换时并发启动、停止和状态回写可能相互交错的问题，改为按顺序处理会话过渡。
- 修复播放页控制栏在启动时的视觉闪烁、响应式布局和媒体详情入口的播放器交互问题。
- 修复字幕未随已选媒体源切换、弹幕与播放器控件重叠，以及播放回退和会话释放时的生命周期边界问题。
- 修复媒体库在后台扫描或 STRM 探测运行时无法删除的问题；删除会请求取消相关任务且不会修改媒体文件，管理台会显示失败原因并即时移除已删除卡片。
- 修复部分 Emby Android 客户端丢失播放鉴权头，以及 Yamby 使用季 ID 请求剧集分集时无法返回正确分集的问题。
- 修复媒体库删除期间后台扫描任务清理不完整，以及 Yamby 无 token 直连播放时的兼容问题。
- 修复 HILLS 等通用 Emby Android 播放器在独立媒体请求中丢失鉴权头导致 401 的问题；PlaybackInfo 现在为可播放媒体源生成绑定用户、条目和媒体源的短期 HMAC 直连票据，并关闭 `AddApiKeyToDirectStreamUrl`，避免长期 token 进入 URL，同时继续兼容标准 Emby 鉴权头和 `api_key`。
- 修复 Emby 客户端访问混合媒体库时的集合类型兼容问题；所有客户端统一收到 Emby 兼容的历史返回形状 `CollectionType: null`，并通过 `TypeOptions` 表示电影和剧集类型，避免 Yamby、VidHub 等客户端丢弃混合媒体库。
- 修复媒体库封面生成后首页、媒体库和管理台列表未及时刷新，以及浏览器继续使用旧封面的缓存问题；封面地址现在带有版本标记，并在生成完成后主动失效相关查询缓存。
- 修复自动生成媒体库封面的标题与副标题间距过小问题，重新调整文字布局以提升封面可读性。
- 修复季度、合集和文件夹等不拥有可删除媒体源的容器显示媒体删除操作的问题，避免将容器 ID 错误提交到媒体源删除接口；剧集项保留剧集级删除入口。
- 修复 Filmly 等 Emby 客户端在媒体流缺少 `Language` 或 `DisplayTitle` 时收到空值的问题，统一提供安全的默认文本，避免详情或播放解析失败。
- 修复扫描任务在索引和后处理阶段的状态与恢复问题：完整索引现在先标记完成，再执行媒体探测、元数据、封面和缩略图后处理；失败目标会保留以便重试，服务重启后可继续未完成的后处理。
- 修复启用媒体库重启后自动封面未及时补齐的问题，服务启动时会重新协调符合条件的媒体库封面，并确保封面生成先于缩略图后处理。
- 延长 Emby 直连播放短期 HMAC 票据至 12 小时，覆盖 VidHub 暂停、切后台或网络恢复后复用播放地址的场景。
- 修复媒体库变更后实时监听器未及时刷新以及失败重启反复过快的问题，监听器会重新加载根路径并对失败重启进行退避。
- 修复远程图片响应缺少 `Content-Length` 时可能无界缓冲，以及登录限流状态持续增长的问题，降低异常请求的资源风险。
- 修复图片尺寸预检结果在写入阶段丢失导致的重复读取和判断不一致问题。

### Changed

- Lux Web 播放页改用模块化 LuxPlayer 呈现层；既有播放能力、鉴权、媒体访问控制和服务端会话接口保持兼容。

- 增加通用 STRM 解析器协议、目标类型识别和插件解析链，支持通过解析器处理 STRM 播放路径。
- 增加两阶段 STRM 缩略图提取、缩略图位置配置、回退策略和管理界面设置。
- 增加持久化用户头像及认证头像 API，支持头像保存后的界面即时刷新。
- 升级 STRM 媒体信息插件至 `0.2.0`，并完善插件协议与打包支持。
- 增加可配置的远程插件商店来源，并提供管理界面和 API 配置入口。

### Fixed

- 改善 Emby/Filmly 媒体库层级、首页媒体库入口和媒体流详情兼容性。
- 修复首页媒体卡片换行、媒体架标题链接和宽屏布局适配问题。
- 修复 STRM 缩略图回退条件，避免在不适用的来源上触发缩略图处理。

### Changed

- 实时增量扫描完成后，针对新增或变化的 STRM 来源创建定向探测任务，与全库定时探测任务分离。
- 优化首页聚合、最近新增目录加载和非首页 Web 路由加载性能。
