# ADR-026：Web 播放档位与服务端 HLS

## 状态

已接受；取代 ADR-004 的当前播放决策。

## 日期

2026-08-26

## 背景

Lux Web 已经支持原生 `video` 播放和浏览器端 HEVC/MKV fallback，但浏览器对容器、视频编码和音频编码的支持并不一致。
当前 ADR-004 只允许直接播放，导致一部分本地媒体无法在 Web 播放。用户要求 Web 播放仍以不转码为优先，同时为本地文件
提供受控的服务端 Remux 和转码能力。

`.strm` 的目标可能包含远程凭据、路径或服务端无法访问的地址。将 `.strm` 拉回服务器处理会改变其直连语义并扩大 SSRF、隐私和资源风险，
因此 `.strm` 必须保持直放专用规则。

## 决策

### 服务端播放档位

服务端为本地媒体使用稳定的 0～4 档播放计划：

- 档位 0：Direct Play。原始文件使用受保护的 Range 端点传输；URL 型 `.strm` 通过受保护入口有限重定向到最终地址。
- 档位 1：Remux。视频和音频均 `copy`，输出 fMP4/CMAF HLS，不改变编码质量。
- 档位 2：Audio Transcode。视频 `copy`，音频转为浏览器可用的 AAC 或配置允许的兼容格式。
- 档位 3：Hardware Transcode。使用可用硬件后端编码视频，音频按需转换。
- 档位 4：Software Transcode。使用 `libx264` 等软件编码器，受管理员策略和独立并发上限控制。

决策顺序始终优先档位 0，其次档位 1，再到档位 2～4。浏览器端 HEVC/MKV fallback 是档位 0 的客户端执行方式，
不伪装成服务端转码档位。

### `.strm` 硬规则

`.strm` 只能产生档位 0 的 Direct Play 计划。目标无法直连、重定向失败或浏览器不支持时返回明确的不支持错误，
不得进入档位 1～4，不得由 Lux 代理媒体字节，也不得调用 `ffprobe` 或 `ffmpeg` 探测/转换远程目标。

### Web 播放会话

Lux Web 使用独立的播放会话 API；Emby 路由、DTO 和播放语义继续保持隔离。播放会话负责：

- 校验用户对条目和媒体源的访问权限；
- 固定一次播放的媒体源、档位、轨道和起播位置；
- 返回短期签名的 Direct 或 HLS 地址；
- 接收幂等的播放事件、心跳和停止请求；
- 管理 HLS 临时目录、ffmpeg 进程组、超时回收和资源配额。

公开播放计划使用判别联合：`DIRECT`、`SERVER_HLS` 或 `UNSUPPORTED`。接口不暴露 ffmpeg 命令行细节。

### 服务端 HLS

服务端 HLS 使用 fMP4/CMAF 播放清单和短分片。`m3u8` 是清单，`init.mp4` 和 `.m4s` 是临时片段；片段按会话生成，
不作为永久媒体副本保存。Safari 使用原生 HLS，其他支持 MSE 的浏览器使用 Web HLS 播放器。

本地文件的 HLS 会话可以从指定起播位置启动；seek 必要时重启当前会话的转码代次。`.strm` 永远不生成 HLS。

### 运行时

运行时统一使用 Jellyfin 官方 `jellyfin-ffmpeg` 项目的最新正式 FFmpeg 7 Release `v7.1.4-3`，
根据目标架构安装对应的 Debian Trixie `.deb`。运行时通过 `/usr/lib/jellyfin-ffmpeg` 优先 PATH，
使 `ffmpeg`、`ffprobe`、缩略图、章节检测和 HLS 执行器使用同一版本；不再安装普通 Debian `ffmpeg`。

## 替代方案

### 只依赖浏览器原生播放

实现简单，但无法覆盖 MKV、HEVC 或不兼容音频，且现有客户端 fallback 对设备性能要求较高。作为档位 0 的首选路径保留，
但不再作为唯一服务端能力。

### 将所有媒体预先转码成新文件

播放前等待时间长、占用大量磁盘，并产生媒体副本。拒绝；HLS 只使用会话临时片段。

### 允许 `.strm` 进入服务端转码

会破坏 `.strm` 直连语义，并引入远程拉流、凭据暴露和资源滥用风险。拒绝。

## 后果

- 本地媒体可以覆盖浏览器不支持容器、音频或视频编码的情况，但服务端需要进程、磁盘、并发和低空间治理。
- 档位 3 的实际可用性取决于 NAS GPU、驱动和 Docker 设备映射，不能仅由 ffmpeg 编译选项宣称。
- 档位 4 默认应受管理员策略限制，避免单个 4K 软件转码拖垮 NAS。
- Web 播放地址不再直接暴露 `.strm` 原始目标；Web 统一通过播放会话获得短期签名地址。
- 外挂字幕可以继续通过独立端点读取；本 ADR 不新增字幕转换、烧录或 DRM。
