# ADR-004：首版只直放

- 状态：已被 ADR-026 取代
- 日期：2026-08-02

## 决定

首版只提供本地文件和 `.strm` 的直接播放，不实现服务端音视频转码、容器转换、字幕转换或 HLS 转码。
服务端只负责受鉴权的原始媒体 Range 传输。Lux Web 可以在后续独立任务中探测浏览器原生解码和客户端解码
能力，但客户端解码不改变服务端的 DirectPlay 语义。

本 ADR 保留为历史记录。当前 Web 播放决策见 ADR-026：本地媒体允许服务端 0～4 档播放计划，`.strm`
仍然只能直放或重定向，绝不进入服务端 Remux、音频转码、视频转码或 HLS。

## 原因

直放是个人 NAS 服务的主要路径，避免把首版复杂度和资源风险集中到转码系统。4K Web 播放优先依赖浏览器和
设备的硬件解码能力；浏览器不支持的编码在客户端增强功能完成前要清晰提示用户使用兼容客户端。

## 后果

PlaybackInfo 只声明真实支持的 DirectPlay 能力；任何服务端转码、Remux 或代理播放需求都必须先修改规格并
新增 ADR，不能伪造客户端能力。客户端探针或自定义解码器的支持范围必须通过独立任务和真实浏览器性能记录确认。
