# ADR-003：独立 Emby 兼容边界

- 状态：已接受（必须遵守）
- 日期：2026-08-02

## 决定

Emby 路由、参数、请求头和 DTO 独立位于兼容层；Lux 自有 API 使用 `/api/v1`，两者都调用 application service，但不共享对外 DTO。

## 原因

目标客户端依赖 Emby 的字段和行为，兼容性怪癖不能反向污染 Lux 领域模型。兼容实现采用 clean-room 的公开协议重实现方式，不复制 Emby 服务端代码或品牌资产。

## 后果

每个已验证的客户端行为都要记录在 `docs/COMPATIBILITY.md`，未实现端点只能按真实客户端请求逐项加入，不能以实现 Swagger 全量端点作为兼容性声明。
