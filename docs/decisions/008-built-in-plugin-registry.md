# ADR-008：内置元数据插件注册表

## 状态

已被 ADR-010 取代。

## 背景

媒体库需要在管理员界面选择元数据刮削器，TMDb 也需要能够被单独启用。直接把 TMDb 分支散落在媒体库 API 和扫描流程中，会让后续增加其他元数据提供方时继续修改公共流程。最初的设计选择了单个 Rust 进程内置实现，但后续需求要求支持可放入插件目录的第三方插件包。

## 决策

该决策已由 ADR-010 取代。原有的稳定插件 ID、管理员权限、配置状态和可空 `scraperId` 仍然保留，但插件实现改为通过动态插件包协议提供。

## 后果

- 新刮削器仍只需声明插件能力，不需要改变媒体库 API 的概念。
- 原始内置实现方案不再适用；插件包必须遵守 ADR-010 的独立进程、签名和权限边界。
