# LUX-031：单电影目录发现实施计划

## 范围

在已存在的电影库根路径中，扫描根目录及其下一层常见电影目录，发现 MKV/MP4 文件，按文件名建立本地确认的电影条目和媒体源，并把结果持久化到 SQLite。此任务不提供客户端媒体浏览接口。

## 规则

- 只处理 `.mkv` 和 `.mp4`，扩展名比较不区分大小写。
- 电影目录可以是根目录直接文件，也可以是根目录下一层目录中的文件；不递归更深层目录。
- 文件名解析支持 `Movie Name (2020).mkv` 和 `Movie.Name.2020.1080p.mkv` 这类常见形式；没有年份时保留标题，年份为空。
- 标题、年份和媒体源路径来自本地文件系统，不调用网络元数据服务。
- 同一个库内相同规范化标题和年份聚合多个媒体源；同一路径重复扫描不产生重复记录。
- 扫描以短事务写入，不在 HTTP 请求中执行。

## 验证门

- `cargo test --locked --all-targets`
- `cargo fmt --all -- --check`
- `cargo clippy --locked --all-targets --all-features -- -D warnings`
- ARM64 本机用一个 MKV/MP4 fixture 完成扫描并核对重启后的记录。

以上验证已于 2026-08-02 在 `arm64` 本机通过。

## 明确不做

- 不读取媒体文件内容。
- 不读取 NFO 或图片。
- 不运行 ffprobe。
- 不实现 Emby Items、图片或播放端点。
