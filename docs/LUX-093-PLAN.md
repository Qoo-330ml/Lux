# LUX-093：认证限流和审计实施记录

## 已完成

- [x] Web 与 Emby 登录共享按来源和用户名隔离的失败限流器。
- [x] 60 秒窗口最多允许 5 次失败；继续失败时正确密码也不立即放行。
- [x] 成功登录清除对应失败计数。
- [x] 远程策略在认证前后均生效，失败响应不暴露用户存在性。
- [x] 管理操作写入 audit_events，并提供管理员分页查询。
- [x] 审计只保存事件类型、目标 ID 和受控 JSON 元数据，不保存凭据或外部 URL。

## 边界

- 登录失败计数是进程内短窗口状态，重启后清空；持久审计事件不包含登录密码失败详情。
- 结构化容器日志和 Fail2Ban 规则仍属于部署阶段。
