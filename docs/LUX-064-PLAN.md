# LUX-064 外挂与内嵌字幕索引

## 范围

在媒体探测阶段保留 ffprobe 返回的内嵌字幕轨，并扫描媒体文件同目录、同媒体文件名的常见外挂字幕。外挂字幕只保存受根目录约束的相对路径，读取时再次执行 ACL、路径 containment 和大小限制检查。

## 实现

- [x] 新增外挂字幕字段和索引：路径、语言、标题、default、forced、格式。
- [x] 识别 `.srt`、`.ass`、`.ssa`、`.vtt`、`.sub`、`.sup`，并解析常见语言标记。
- [x] 把内嵌和外挂轨统一写入 `media_streams`，外挂轨使用不与内嵌轨冲突的 stream index。
- [x] 新增 Lux 和 Emby 字幕读取端点，支持 GET/HEAD 和媒体源显式选择。
- [x] 字幕读取执行媒体库 ACL、根目录 containment、符号链接解析和 10 MiB 大小限制。

## 验证

- 多语言、多格式、forced 标记 fixture 验证索引结果。
- Emby 字幕读取集成测试验证内容、Content-Type 和无权限 404。
- ARM64 上通过 clippy、字幕集成测试和全量回归。

## 明确不做

- 本阶段不抽取或转码内嵌字幕；内嵌字幕仍由客户端从媒体容器读取。
- 本阶段不提供在线字幕搜索、下载、OCR 或字幕格式转换。
