# LUX-153 计划：管理员控制台 SSE 实时更新

## 目标

管理员控制台通过同源 SSE 接收服务端数据变更通知，自动失效对应的 React Query
缓存，移除页面右上角的手动刷新按钮。页面打开时只建立一条连接；浏览器负责断线重连，
连接恢复后前端主动补偿一次管理员查询。

## SSE 契约

- `GET /api/v1/admin/events` 只允许已登录且具有 `canManageServer` 的 Web session；
  读取不要求 CSRF。
- 响应使用 `text/event-stream; charset=utf-8`，禁止缓存，并设置 `X-Accel-Buffering: no`。
- 首帧为 `event: ready`，数据为 `{"version":1}`。
- 数据变更使用 `event: invalidate`，当前数据格式为 `{"scope":"jobs"}`。
- `scope` 固定为 `all`、`dashboard`、`jobs`、`libraries`、`plugins`、`users`、
  `metadata` 或 `settings`。
- 服务端每 15 秒发送 SSE 注释心跳；客户端不把心跳当作数据事件。
- 广播缓冲区发生丢帧时发送 `all` 作用域，客户端重新读取所有活动管理员查询。

## 事件范围

| 作用域 | 失效查询 |
| --- | --- |
| `all` | 所有管理员查询 |
| `dashboard` | 仪表盘、审计日志 |
| `jobs` | 扫描任务、元数据任务、注册任务、仪表盘、审计日志 |
| `libraries` | 媒体库、注册任务、仪表盘、审计日志 |
| `plugins` | 插件商店、已安装插件、媒体库、审计日志 |
| `users` | 用户、用户媒体库 ACL、媒体库、仪表盘、审计日志 |
| `metadata` | 待处理候选、元数据任务、审计日志 |
| `settings` | 服务端设置、仪表盘、审计日志 |

## 实施切片

1. 增加进程内管理员事件广播、SSE 路由和作用域映射；活动、扫描和元数据任务写入后发布通知。
2. 在 `AdminLayout` 挂载单一 SSE 订阅，连接打开时补偿查询，卸载时关闭连接。
3. 删除仪表盘、任务、插件和元数据页面的页面级刷新按钮，保留扫描、刮削、取消和重试等主动命令。
4. 增加 Rust API/活动事件测试、Web SSE 生命周期和查询失效测试，并更新 API 与开发规格。

## 验收

- [ ] 未认证请求和非管理员请求不能读取 SSE 流。
- [ ] 管理员收到 `ready`、作用域失效事件和 15 秒心跳；广播丢帧会退化为 `all`。
- [ ] 播放开始、暂停、停止和登录活动会触发 `dashboard`；扫描、元数据任务、插件、用户、媒体库和设置变更触发对应作用域。
- [ ] 管理布局同一时间只建立一条 SSE 连接，卸载时关闭；重连后补偿所有当前管理员查询。
- [ ] 所有页面级刷新按钮移除，主动后台操作按钮保持可用。
- [ ] Rust/Web 测试、格式化、Clippy 和 Web 构建通过；ARM 本机记录 `uname -m`，不宣称 NAS/x86 性能。

## 不在本任务内

- 不把 SSE 扩展为普通用户实时推送或 Emby 兼容层实时协议。
- 不用 SSE 传输业务数据、凭据、完整审计内容或媒体内容；客户端收到通知后重新读取受保护 API。
- 不删除仪表盘资源指标的低频刷新；SSE 负责变更通知，资源采样仍按低频间隔更新。
