# LUX-052：候选搜索和保守匹配实施计划

## 范围

将 TMDb 候选响应与本地电影身份输入连接起来，使用可解释的字段评分做保守确认：provider ID 精确命中优先；规范化标题和年份精确匹配才自动确认；同名、缺年份、近似标题或候选并列都进入 `PENDING`。

## 实现

- [x] 增加标题规范化和 Unicode 字符安全比较。
- [x] 增加 provider ID 精确确认和电影详情编排。
- [x] 增加标题+年份高置信确认、编辑距离近似评分和并列候选保护。
- [x] 增加中文、英文、同名翻拍、缺年份和近似标题的表驱动测试。

## 明确不做

- 不把低置信候选自动写入媒体条目。
- 不实现待处理管理 API、候选预览或人工确认；属于 LUX-053 及后续纵切片。
